1. Como Usar o Sistema no Dia a Dia

1.1 Tela de Login

Acesse a URL do sistema (ex: https://bagpoint.vercel.app), insira seu e-mail e senha e clique em Entrar.

💡 Apenas usuários cadastrados pelo admin conseguem fazer login. Se sua conta foi desativada, aparecerá um aviso na tela.

1.2 Novo Check-in

1
Clique em "Novo Check-in" no menu lateral

Preencha nome completo e telefone (WhatsApp) do cliente.

2
Selecione a categoria de cada mala

Clique no card da categoria (Small Bag, Cabin Size, Large Luggage ou Special Items). O valor cobrado é sugerido automaticamente com base nas categorias.

3
Ajuste o valor cobrado se necessário

O campo é editável — você pode mudar para meio período ou outro valor combinado.

4
Selecione o parceiro (opcional)

Se o cliente veio indicado por um hotel, airbnb ou hostel, selecione o parceiro. Para criar um novo parceiro, clique em "+ Novo parceiro".

5
Clique em "Registrar Check-in"

Um protocolo único é gerado (ex: BP-20260318-001). Você é redirecionado para a página de detalhes onde pode adicionar fotos e enviar o WhatsApp.

1.3 Enviar WhatsApp ao Cliente

Na página de detalhes do check-in, clique no botão verde WhatsApp. Isso abre o WhatsApp Web/app com a mensagem pré-preenchida incluindo o protocolo, horário e a assinatura Bag Point.

1.4 Registrar Retirada

1
Clique em "Retirada" no menu lateral

Busque pelo número do protocolo ou nome do cliente.

2
Confirme a retirada

Verifique os itens e clique em "Confirmar Retirada". O status é atualizado para "retirado".

3
Envie o WhatsApp de confirmação

Clique no botão WhatsApp para enviar a mensagem de saída ao cliente.

1.5 Adicionar Fotos

Na página de detalhes do atendimento (após o check-in), clique em Selecionar Fotos. No celular, a câmera traseira abre diretamente. Selecione e clique em Enviar fotos.

1.6 Relatório Geral

Menu lateral → Relatório. Filtre por período, veja totais de atendimentos e valor faturado. Exporte para CSV para abrir no Excel.

1.7 Relatório de Parceiros (Admin)

Menu lateral → Parceiros. Filtre pelo mês desejado, visualize quantos atendimentos cada parceiro gerou e o valor total. Exporte para CSV para calcular comissões.

2. Configurar o Supabase

2.1 Criar Conta e Projeto

1
Acesse https://supabase.com e crie uma conta gratuita
2
Clique em "New Project"

Dê um nome (ex: bagpoint), escolha uma senha forte para o banco, selecione a região South America (São Paulo).

3
Aguarde o projeto ser criado

Leva cerca de 1-2 minutos. Após isso, anote a URL do projeto.

2.2 Obter as Chaves de API

No painel do Supabase, vá em Project Settings → API:

ChaveOnde ficaPara que serve
NEXT_PUBLIC_SUPABASE_URL Project URL Endereço do banco (público)
NEXT_PUBLIC_SUPABASE_ANON_KEY Project API Keys → anon / public Chave pública para o frontend
SUPABASE_SERVICE_ROLE_KEY Project API Keys → service_role (secret) Chave admin — criar usuários pelo sistema
⚠️ A service_role key é secreta — nunca a exponha no frontend ou em repositórios públicos. Use apenas em variáveis de ambiente do servidor.

2.3 Rodar as Migrações SQL

No Supabase, vá em SQL Editor e execute os arquivos da pasta supabase/migrations/ do projeto em ordem:

  1. 001_initial_schema.sql — tabelas principais
  2. 002_storage_and_photos.sql — bucket de fotos
  3. 003_add_parceiros.sql — tabela de parceiros

3. Hospedar na Vercel

3.1 Criar Conta na Vercel

1
Acesse https://vercel.com e crie uma conta gratuita

Recomendado: faça login com sua conta do GitHub.

3.2 Enviar o Código para o GitHub

1
Crie um repositório privado no GitHub

Acesse https://github.com/new, dê um nome (ex: bagpoint), selecione Private.

2
Suba o código com os comandos abaixo (no terminal)
# Na pasta do projeto: git init git add . git commit -m "feat: bag point system" git remote add origin https://github.com/SEU_USUARIO/bagpoint.git git push -u origin main

3.3 Importar na Vercel

1
Na Vercel, clique em "Add New → Project"

Selecione o repositório bagpoint do GitHub.

2
Configure as variáveis de ambiente

Antes de clicar em Deploy, adicione todas as variáveis (ver seção 4).

3
Clique em "Deploy"

A Vercel faz o build e publica automaticamente. Em 1-2 minutos o sistema estará no ar.

✅ A cada vez que você fizer push no GitHub, a Vercel atualiza o sistema automaticamente.

4. Variáveis de Ambiente

Configure estas variáveis em Vercel → Project → Settings → Environment Variables (e também no arquivo .env.local para rodar localmente):

# .env.local — NÃO commitar este arquivo no git NEXT_PUBLIC_SUPABASE_URL=https://SEU_PROJETO.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6... SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6...service_role...
VariávelObrigatóriaDescrição
NEXT_PUBLIC_SUPABASE_URL ✓ Sim URL do projeto Supabase
NEXT_PUBLIC_SUPABASE_ANON_KEY ✓ Sim Chave pública anon do Supabase
SUPABASE_SERVICE_ROLE_KEY Para criar usuários Chave secreta service_role — habilita criação de usuários pelo admin
⚠️ Verifique que o arquivo .env.local está no .gitignore para não expor as chaves.

5. Criar o Primeiro Usuário Admin

Na primeira vez, o admin precisa ser criado diretamente pelo Supabase (antes de o sistema estar configurado):

1
No Supabase → Authentication → Users → "Add User"

Preencha e-mail e senha e clique em Create User.

2
Copie o ID do usuário criado

É um UUID no formato: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

3
No SQL Editor, execute:
INSERT INTO public.usuarios (id, nome, email, role, ativo) VALUES ( 'COLE_O_UUID_AQUI', 'Nome do Admin', 'admin@bagpoint.com', 'admin', true );
4
Faça login no sistema com o e-mail e senha criados

A partir daí, novos operadores podem ser criados diretamente pelo sistema.

6. Gerenciar Usuários pelo Sistema

Após configurar a SUPABASE_SERVICE_ROLE_KEY, o admin pode criar operadores sem sair do sistema:

1
Menu lateral → Usuários
2
Clique em "Novo Usuário"

Preencha Nome, E-mail, Senha e selecione o papel (Operador ou Admin).

3
Clique em "Criar usuário"

O operador pode logar imediatamente com o e-mail e senha definidos.

Na mesma página é possível:

  • Alterar o papel de um usuário (admin ↔ operador)
  • Desativar uma conta (o operador não consegue mais logar)

7. Manutenção e Atualizações

7.1 Atualizar o Sistema

Qualquer alteração no código é publicada automaticamente:

git add . git commit -m "fix: descrição da mudança" git push

A Vercel detecta o push e faz o redeploy em ~1 minuto.

7.2 Banco de Dados — Backup

O Supabase faz backups diários automáticos (plano gratuito: 7 dias de retenção). Para backup manual, vá em Database → Backups.

7.3 Limites do Plano Gratuito

ServiçoLimite Gratuito
Vercel100 GB de banda / mês, deploys ilimitados
Supabase — Banco500 MB de armazenamento
Supabase — Storage (fotos)1 GB de armazenamento
Supabase — Auth50.000 usuários ativos / mês
💡 Para uso intenso com muitas fotos, considere fazer upload em resolução reduzida ou migrar o storage para um plano pago do Supabase (~US$ 25/mês).

7.4 Domínio Personalizado (opcional)

Para usar um domínio próprio (ex: sistema.bagpoint.com.br):

  1. Na Vercel → Project → Settings → Domains
  2. Adicione o domínio e siga as instruções para configurar o DNS
  3. O certificado SSL é emitido automaticamente pela Vercel

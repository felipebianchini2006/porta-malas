Visão Geral

O Bag Point é um sistema web de gerenciamento de guarda-bagagens desenvolvido sob medida. Permite registrar check-ins de bagagens, acompanhar itens em guarda, controlar retiradas, registrar parceiros de indicação e gerar relatórios financeiros e operacionais.

Frontend Next.js 15 (App Router) · React · TypeScript · Tailwind CSS · shadcn/ui
Backend / Banco de Dados Supabase (PostgreSQL) · Row Level Security · Supabase Auth · Storage
Hospedagem Vercel (deploy automático via GitHub)
Armazenamento de Fotos Supabase Storage · Bucket público fotos-malas

Funcionalidades Implementadas

✓ Concluído Branding Bag Point

Interface completamente personalizada com a identidade visual da marca.

  • Logo oficial na tela de login
  • Cor âmbar (#f5c42c) substituindo o roxo genérico em todo o sistema
  • Nome "Bag Point" na barra lateral, header mobile e título da aba do navegador
  • Ícone 🧳 na sidebar desktop e mobile

✓ Concluído Check-in de Bagagens

Registro completo da entrada de bagagens com geração automática de protocolo.

  • Dados do cliente: nome e telefone/WhatsApp
  • Campo de valor cobrado com sugestão automática baseada nas categorias selecionadas
  • Múltiplas malas por atendimento, cada uma com ID interno e categoria
  • Campo de observações
  • Campo de parceiro (opcional) — rastreia indicações
  • Protocolo único gerado automaticamente (ex: BP-20260318-001)

✓ Concluído Categorias de Mala com Preço

4 categorias pré-definidas substituem o campo de texto livre, padronizando o cadastro e automatizando a sugestão de valor.

O campo "Valor cobrado" é sempre editável — a sugestão serve como base, o operador pode ajustar.

✓ Concluído Sistema de Parceiros

Rastreamento de indicações por parceiro para comissionamento mensal.

  • 5 tipos de parceiro: Hotel, Airbnb, Hostel, Rua, Outro
  • Cadastro de parceiro diretamente no check-in (sem sair da tela)
  • Campo parceiro é opcional — não bloqueia o atendimento
  • Tabela parceiros com RLS no Supabase
  • FK parceiro_id na tabela atendimentos

✓ Concluído Relatório de Parceiros

Página dedicada para calcular comissões ao fim do mês.

  • Filtro por período (de/até)
  • Tabela: Parceiro | Tipo | Nº Atendimentos | Valor Total
  • Totalizadores no cabeçalho da tabela
  • Exportação para CSV (separador ";", UTF-8 com BOM para Excel)
  • Visível apenas para perfil admin no menu lateral

✓ Concluído Criação de Usuários pelo Admin

O administrador pode criar operadores sem precisar acessar o Supabase Dashboard.

  • Botão "Novo Usuário" na página de Gerenciar Usuários
  • Dialog com campos: Nome, E-mail, Senha, Papel (admin/operador)
  • Usa Supabase Admin API com service_role key
  • Usuário criado já com e-mail confirmado (pode logar imediatamente)
⚠️ Requer a variável de ambiente SUPABASE_SERVICE_ROLE_KEY configurada no servidor. Ver seção de configuração.

✓ Concluído Assinatura Bag Point no WhatsApp

Todas as mensagens enviadas via WhatsApp incluem a assinatura da marca.

  • Mensagem de check-in: confirma protocolo + horário + assinatura
  • Mensagem de retirada: confirma saída + agradecimento + assinatura
  • Assinatura: — *Bag Point* 🧳 / guarda-bagagens

✓ Concluído Câmera Mobile no Upload de Fotos

No celular, o botão de upload abre diretamente a câmera traseira.

  • Atributo capture="environment" no input de arquivo
  • Funciona em iOS Safari e Android Chrome
  • Fotos enviadas diretamente ao Supabase Storage

Base Retirada de Bagagens

  • Busca por protocolo ou nome do cliente
  • Confirmação de retirada com registro de horário
  • Link WhatsApp gerado automaticamente com assinatura Bag Point

Base Dashboard Operacional

  • Contadores: bagagens em guarda, entradas hoje, retiradas hoje
  • Tabela de atendimentos ativos com protocolo, cliente, status

Base Relatório Geral

  • Filtro por período com atalhos (Hoje, Esta semana)
  • Totais: atendimentos, entradas, retiradas, em guarda, valor total
  • Exportação CSV
